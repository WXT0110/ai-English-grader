# AI English Grader (高中英语 AI 批改助手)

An AI-powered web tool for high school students to grade their English essays. Built with HTML, Tailwind CSS, and DeepSeek API.

## 🌟 Features (项目特色)
- **双题型支持**: 支持应用文 (15分) 与 读后续写 (25分) 的智能批改。
- **特级教师级 Prompt**: 深度定制的系统提示词，提供逐句语法纠错、高级词汇替换及提分建议。
- **极简 UI**: 采用极简学术风设计，手机电脑完美适配。
